# Contratos de Agentes

Esta pasta contém contratos e requisitos específicos para cada agente da organização.

Cada contrato deve incluir:

- identidade do agente;
- escopo de autoridade;
- permissões;
- entradas esperadas;
- saídas obrigatórias;
- regras de escalonamento e evidência.

Use os esquemas definidos em `schemas/` para validar as estruturas de projeto, tarefa, artefato, decisão e evento.
